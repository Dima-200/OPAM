## Завдання 2. Рекурсивний пошук максимуму

Створено масив із 16 випадкових цілих чисел у діапазоні від -20 до 20. Для генерації використано `new Random(3)`, що забезпечує відтворюваність результатів.

Функція `MaxRecursive` використовує метод поділу навпіл: масив ділиться на дві частини, у кожній рекурсивно знаходиться максимум, після чого порівнюються отримані значення.

**Базовий випадок:** якщо діапазон містить один елемент (`lo == hi`), функція повертає цей елемент.

**Масив:**

```text

```

**Результати:**

- Максимальний елемент: 18

- `log2(16) = 4`

Глибина рекурсії дорівнює 5, якщо рахувати початковий виклик як перший рівень. Значення `log2(16) = 4` показує кількість поділів навпіл до одиничного елемента.

## Завдання 3. Пошук усіх шляхів у матриці 3×3

Реалізовано рекурсивний алгоритм із поверненням назад (*backtracking*), який знаходить усі шляхи від верхньої лівої клітинки до нижньої правої. Дозволені рухи — лише праворуч і вниз.

**Базовий випадок:** рекурсія завершується, коли досягнуто нижньої правої клітинки матриці.

Позначення:
- `R` — рух праворуч;
- `D` — рух униз.

**Знайдені шляхи:**

```text
RRDD
RDRD
RDDR
DRRD
DRDR
DDRR
```

**Кількість шляхів:** 6.

Кожен шлях містить два рухи праворуч і два рухи вниз.

## Завдання 4. Трасування рекурсії

Для масиву з чотирьох елементів `{7, -2, 15, 4}` виконано трасування рекурсивних викликів функції `TraceMax`.

**Базовий випадок:** коли діапазон містить один елемент (`lo == hi`), функція виводить цей елемент як результат.

**Результат трасування:**

```text
enter Max(0..3)
  enter Max(0..1)
    enter Max(0..0)
    exit Max(0..0) -> 7
    enter Max(1..1)
    exit Max(1..1) -> -2
  exit Max(0..1) -> 7
  enter Max(2..3)
    enter Max(2..2)
    exit Max(2..2) -> 15
    enter Max(3..3)
    exit Max(3..3) -> 4
  exit Max(2..3) -> 15
exit Max(0..3) -> 15
```

**Максимум:** 15.

Під час виконання рекурсії спочатку відбувається спуск до базових випадків. Після їх досягнення функції повертають результати, тому повідомлення `exit` з'являються під час повернення з рекурсивних викликів.

## Завдання 5. Порівняння рекурсивного та ітеративного алгоритмів

Для перевірки результат рекурсивного пошуку максимуму порівняно з ітеративним алгоритмом, який використовує цикл.

**Результат виконання:**

```text
Рекурсивно: 18
Циклом: 18
Результати збігаються: True
```

Обидва алгоритми знайшли однаковий максимальний елемент — 18.

**Який алгоритм зрозуміліший і чому?**

Для звичайного пошуку максимуму в масиві ітеративний алгоритм із циклом зазвичай простіший для розуміння, оскільки послідовно перевіряє кожен елемент. Рекурсивний алгоритм краще демонструє принцип поділу задачі на менші підзадачі.

**Як виконати ітеративний обхід вкладених папок?**

Для ітеративного обходу можна використовувати стек або чергу. У них зберігаються папки, які потрібно обробити. Цикл бере наступну папку, обробляє її та додає вкладені папки до структури. Це дозволяє обійти файлову систему без рекурсивних викликів.
