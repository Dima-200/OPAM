# Лабораторна робота 2. Алгоритми обробки масивів

Варіант: масив з 18 випадкових чисел у діапазоні [-3; 3], `new Random(3)`.
Критерій фільтрації: елементи більші за 1 (K % 5).
Перестановка: від'ємні та нульові елементи на початок, решта в кінець.
Матриця: 6 × 3, діапазон [-3; 3].

## Де що реалізовано

| Завдання | Метод |
|---|---|
| 1. Агрегація за один прохід | `Aggregate`, `PrintAggregate` |
| 2. Фільтрація в новий масив | `Filter` |
| 3. Найдовша серія | `LongestRun`, `PrintRun` |
| 4. Перестановка на місці | `MoveNonPositiveToFront` |
| 5. Матриця | `CreateMatrix`, `RowSums`, `ColumnMax`, `IndexOfMax` |
| 6. Крайові випадки | `EdgeCases` |

Рядки матриці нумеруються з 0.
