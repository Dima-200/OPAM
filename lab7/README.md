## Завдання 5. Захоплення змінних
Вивід: _встав фактичний вивід_ (очікувано: `False`; `3, 3, 3`; `0, 1, 2`)

1. **Змінна після лямбди.** Лямбда захоплює саму змінну `threshold`, а не її значення на момент створення. Коли ми поклали в неї 1000, делегат при виклику побачив уже нове значення, тому `above(10)` дало `False`, а не `True`.
2. **Лічильник `for`.** Змінна `i` оголошена один раз на весь цикл, і всі три лямбди захоплюють одну й ту саму змінну. Після завершення циклу `i == 3`, тому всі повертають 3.
3. **`foreach`.** У `foreach` змінна циклу створюється заново на кожній ітерації, тож кожна лямбда захоплює власну копію і повертає 0, 1, 2.
